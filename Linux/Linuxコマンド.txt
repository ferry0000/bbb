

cd ディレクトリ名　ディレクトリに移動
cd ..　1階層上のディレクトリに移動
cd ../..　2階層上のディレクトリに移動
cd　ホームディレクトリに移動
cd ~　ホームディレクトリに移動
cd /　ルートディレクトリに移動
cd -　直前のディレクトリに移動
cd $_　mkdirしたディレクトリに移動

ls　ファイル一覧「list」
ls -l　ファイルの属性の一覧「long list」
ls -a　隠しファイル表示

pwd　カレント・ディレクトリを取得「print working directory」

cat ファイル名　ファイルの中身を確認
cat -n ファイル名　行番号付き

head -n n　先頭のn行を抜き出す
tail -n n　末尾のn行を抜き出す

echo　文字列を表示
echo $環境変数名　環境変数を表示
echo "こんにちは" > hello.txt　ファイル新規作成or上書き


cp コピー元ファイル コピー先ディレクトリ　ファイルコピー
cp -r コピー元ディレクトリ コピー先ディレクトリ
cp -a　属性保持コピー

mv ファイル名 目的のディレクトリ　ファイル移動
mv 元ファイル名 新規ファイル名　ファイルリネーム

mkdir ディレクトリ名　ディレクトリ作成
mkdir -p ディレクトリ名/ディレクトリ名/ディレクトリ名　ディレクトリ再帰作成

rm ファイル名　ファイル削除
rm ファイル名1 ファイル名2　複数ファイル削除
rm -r ディレクトリ名　ディレクトリ削除
rm -rf ディレクトリ名　ディレクトリ強制削除（確認なし）

sudo コマンド名　root権限で実行
sudo -i　root権限でログイン



Tab　入力補完
　　　入力候補が複数ある場合、再度Tabで、入力候補が表示

grep [オプション] '検索文字列' 対象ファイル　ファイル内の文字列を検索
オプション
-n	マッチした行の行番号を表示
-i	大文字小文字を区別せずに検索
-r	ディレクトリ内の全てのファイルを再帰的に検索
-l	ファイル名だけを表示
-C n　前後n行表示
-E　拡張正規表現
--include="*.log" ログファイルのみ
オプション例
-irl
-rniE "error|exception|fail"
-rni --include="*.log" --include="*.out"

find 検索先ディレクトリ -name "ファイル名"　ファイルやディレクトリ検索

history　コマンド履歴

less ファイル名　テキストファイルの表示
終了→:q

vi ファイル名　テキストファイルの閲覧と編集
              無いファイル名指定で新規作成
　　　　　　　　「NORMAL」モード→Esc
　　　　　　　　　　終了→:q
　　　　　　　　　　強制終了→:q!
　　　　　　　　　　上書き保存→:w
　　　　　　　　　　保存して終了→:wq または :x
　　　　　　　　　　名前をつけて保存→:w ファイル名
　　　　　　　　　
　　　　　　　　「INSERT」モード→i

sed 's/foo/bar/' file.txt　foo → bar に置換して標準出力
sed 's/foo/bar/g' file.txt　全置換して標準出力
sed -i 's/foo/bar/g' file.txt　ファイル書き換え
sed -i.bak 's/foo/bar/g' file.txt　バックアップ付き
sed '/ERROR/s/foo/bar/' file.txt　ERROR を含む行だけ対象
sed 's/f.o/bar/' file.txt　任意文字
sed 's/fo*/bar/' file.txt　繰り返し
sed -i 's|baseurl=.*|#&|' file　マッチした文字列（&）をコメントアウト
sed -i 's|#mirrorlist=|mirrorlist=|' file　コメント解除


view ファイル名　参照専用vi

man コマンド名　マニュアル表示

which コマンド名　コマンド実行パス表示

w　ユーザーのログイン情報
whoami　自分のユーザー

cat /etc/passwd　ユーザー一覧（UID）
cat /etc/group　グループ一覧（GID）

env　環境変数

ps　プロセスの実行状態
ps -ef　全プロセスの詳細一覧
ps -ef | grep oracle

free -h　メモリ確認

top　実行中のプロセスをリアルタイム表示
htop

chmod　アクセス権限（パーミッション）の変更

ifconfig　ネットワークインターフェースの設定情報

source ファイル名　設定などを即時反映
source ~/.bashrc

diff ファイル名 ファイル名　二つのファイルの差分を表示

scp ローカルファイル名 ユーザー名@ホスト名:リモートサーバディレクトリ　ローカルからリモートサーバにファイルをコピー
scp -r ローカルディレクトリ名 ユーザー名@ホスト名:リモートサーバディレクトリ　ローカルからリモートサーバにディレクトリをコピー

タイムゾーン
timedatectl
ls -l /etc/localtime

パイプライン

[コマンド1] | [コマンド2]	コマンド1の標準出力をコマンド2の標準入力に渡す
ps aux | grep 調べたいプロセス名

[コマンド1] | xargs  [コマンド2]	コマンド1の標準出力を引数に変換して、コマンド2に渡す
find . -name "*.log" | xargs rm
＝rm file1 file2 file3 …

[コマンド] < [ファイル]	ファイルの内容をコマンドの標準入力に渡す

[コマンド] > [ファイル]	コマンドの標準出力をファイルに出力する
grep -rl "error" . > result.txt　現在ディレクトリ以下のファイルの中に"error"を含むファイルの相対パスを result.txt に出力
grep -rl "error" "$(pwd)" > result.txt　現在ディレクトリ以下のファイルの中に"error"を含むファイルの絶対パスを result.txt に出力
grep -rl "error" 指定ディレクトリ絶対パス > result.txt　指定ディレクトリ以下のファイルの中に"error"を含むファイルの絶対パスを result.txt に出力

[コマンド] >> [ファイル]	コマンドの標準出力をファイルに追記する
date --iso-8601=seconds >> log.txt　ISO-8601形式の現在日時を追記
