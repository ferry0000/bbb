## 1. VS Codeで「2つのファイル」を差分比較する方法

### 方法A: エクスプローラーから比較

1. 比較したい1つ目のファイルを右クリック
2. **「比較対象の選択」**
3. 比較したい2つ目のファイルを右クリック
4. **「選択項目と比較」**

これで左右に並んだ差分画面が開きます。

---

### 方法B: タブを開いた状態で比較

開いているファイル同士でも比較できます。

1. 1つ目のタブを右クリック
2. **「比較対象の選択」**
3. 2つ目のタブを右クリック
4. **「選択項目と比較」**

---

## 2. コピペした「テキスト同士」を比較したい場合

ファイルではなく、単純に文章やコードの断片を比較したいこともあります。
その場合は一度2つのテキストを別ファイルに貼り付けるのが基本です。

### 手順

1. 新しいテキストファイルを2つ作る
2. 比較したい内容をそれぞれ貼る
3. 上の方法で比較する

たとえば

* `before.txt`
* `after.txt`

のように作って比較します。

---

## 3. 保存していない変更を元ファイルと比較する方法

既存ファイルを編集中なら、VS Code は自動で変更差分を見やすく表示できます。

### 例

Git管理されている場合:

* 左側の**ソース管理**アイコンを開く
* 変更されたファイルをクリック

すると、

* 元の内容
* 今の内容

が並んで表示されます。

Gitを使っていると最も便利です。

---

## 4. 選択した部分だけ比較したい場合

標準機能だけだと少し弱いです。
その場合は拡張機能を使う方法があります。

よく使われる方向性は次です。

* **Partial Diff**
* **Select Compare**
* **Compare Folders**

これらを使うと、

* 選択範囲同士の比較
* クリップボードとの比較
* フォルダ単位の比較

がしやすくなります。

---

## 5. フォルダごと差分比較したい場合

VS Code単体では少し弱いです。
拡張機能か外部ツールを使うのが一般的です。

よく使われる外部ツール:

* **WinMerge**（Windows）
* **Meld**
* **Beyond Compare**

特に Windows なら **WinMerge** が分かりやすいです。
ファイル単位だけでなく、フォルダ単位でも比較できます。

---

## 6. コマンドラインで比較する方法

### Windows

* `fc` コマンド
* Gitを入れていれば `git diff`

### Linux / WSL

* `diff`
* `vimdiff`
* `git diff`

例:

```bash
diff file1.txt file2.txt
```

横並びで見やすくしたいなら:

```bash
vimdiff file1.txt file2.txt
```

## 7. 一番おすすめの使い分け

### 2ファイル比較

### 編集前後の比較

Git + VS Code が最も便利です。

### 一時的な文章比較

2つの一時ファイルを作ってVS Codeで比較。

### フォルダ単位比較

WinMerge などの専用ツールが便利です。

## 8. よくあるつまずき

### 「比較対象の選択」が見つからない

ファイルを右クリックした場所が違うことがあります。
エクスプローラー上のファイル名を右クリックしてください。

### 比較結果が出ない

1つ目で **比較対象の選択** をした後、2つ目で **選択項目と比較** を押す必要があります。

あります。主な原因は次のどれかです。

1. **右クリックしている場所が違う**
   `Select for Compare` は、**Explorer のファイル**を右クリックしたときに出る標準メニューです。公式ドキュメントでも、Explorer 上の1つ目のファイルで `Select for Compare`、2つ目で `Compare with Selected` とされています。([Visual Studio Code][1])

2. **フォルダを開いていない / Explorer ではない場所で操作している**
   空のウィンドウや、単なるエディタ本文上の右クリックでは、比較メニューが出ないことがあります。過去の既知事例でも、**フォルダを開いた状態なら比較できるが、空の新規ウィンドウでは出ない**という挙動が報告されています。([GitHub][2])

3. **最近のバージョンでコンテキストメニュー表示が不安定**
   VS Code 1.110.1 では、Windows で右クリックメニュー項目の一部が出ない不具合報告があります。これは `Open with Code` の件ですが、**最近のバージョンで右クリックメニュー周りが不安定な可能性**はあります。([GitHub][3])

まずこれを試してください。

## 確実な手順

### 方法1

1. **フォルダを開く**
   `ファイル` → `フォルダーを開く`

2. 左の **Explorer** を開く
   `Ctrl + Shift + E`

3. 比較したい1つ目の**ファイル名**を右クリック
   → **Select for Compare**

4. 2つ目の**ファイル名**を右クリック
   → **Compare with Selected** ([Visual Studio Code][1])

---

## それでも出ない場合の代替方法

### 方法2: コマンドパレットから比較

VS Code にはコマンドパレット経由の比較もあります。
`Ctrl + Shift + P` を押して、`compare` と入力して比較系コマンドを探してください。公式にも、**新しい無題テキスト同士を比較するコマンド**があります。([Visual Studio Code][1])

### 方法3: コマンドラインで開く

ターミナルから次で比較できます。公式に `--diff` オプションがあります。([Visual Studio Code][1])

```bash
code --diff file1.txt file2.txt
```

Windows でも `code` コマンドが通っていれば使えます。

---

## よくある見落とし

* **タブ本文上を右クリックしている**
  → 出ないことがあります。**Explorer のファイル名**でやってください。
* **比較したい対象が未保存の無題ファイルだけ**
  → 標準の右クリック比較が出にくいことがあります。保存するか、コマンドパレット側を使います。([Visual Studio Code][1])
* **1ファイルしかない状態**
  → 1つ目で `Select for Compare` したあと、2つ目が必要です。([Visual Studio Code][1])

## すぐ確認してほしい点

あなたの画面で確認したいのはこの3点です。

* VS Code で**フォルダを開いているか**
* 左の **Explorer** の**ファイル名**を右クリックしているか
* 比較したいファイルが**2つとも保存済み**か

必要なら次に、**あなたの VS Code の画面に合わせて「どこを右クリックするか」だけを1手順ずつ**案内します。
