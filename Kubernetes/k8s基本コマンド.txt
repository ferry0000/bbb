

ノード一覧
kubectl get nodes
kubectl get nodes -o wide

Pod一覧
kubectl get pods -A

Pod詳細
kubectl describe pod <Pod名>

テストPod作成
kubectl run nginx --image=nginx
テストPod削除
kubectl delete pod nginx

yaml適用
kubectl apply -f file.yaml

Podログ
kubectl logs <Pod名>
kubectl logs -f <Pod名>

kubectl exec -it <Pod名> -- sh

CPU・メモリ確認
kubectl top pods -A
kubectl top nodes
sudo crictl stats　コンテナランタイム（containerd）レベル

リソース一覧
kubectl api-resources
Pod:po
Node:no
Service:svc
StorageClass:sc
ersistentVolumeClaim:pvc
PersistentVolume:pv
LimitRange:limits
ConfigMap:cm


イメージインポート
sudo k3s ctr -n k8s.io images import my-oracle-free-custom.tar

イメージ一覧
sudo crictl images
sudo k3s ctr -n k8s.io images ls

k3sで直接イメージpull
sudo crictl pull nginx:latest
sudo k3s ctr -n k8s.io images pull docker.io/library/nginx:latest

イメージ削除
sudo crictl rmi イメージ名:タグ名
sudo k3s ctr -n k8s.io images rm イメージ名:タグ名

イメージ情報
sudo crictl inspecti my-app:latest

コンテナ一覧
sudo crictl ps

コンテナログ
sudo crictl logs コンテナID

イメージエクスポート
sudo ctr -n k8s.io images export my-app.tar my-app:latest

nerdctlでDockerfileからビルド
sudo nerdctl -n k8s.io build -t my-app:latest .
nerdctlでエクスポート・インポート
nerdctl save -o image.tar my-app:latest
nerdctl load -i image.tar
